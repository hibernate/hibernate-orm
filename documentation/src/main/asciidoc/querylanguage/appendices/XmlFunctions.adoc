== XML functions

:ql-xml-example-dir: {core-project-dir}/src/test/java/org/hibernate/orm/test/function/xml
:ql-function-extras-dir: {doc-main-asciidoc-dir}/querylanguage/extras

The following functions deal with SQL XML types, which are not supported on every database.
See <<ql-xml-dialect-support,dialect support>> for availability and version profiles.
For Java attribute mappings, see link:{doc-user-guide-url}#basic-xml[XML mappings] in the User Guide.

| <<hql-xmlelement-function,`xmlelement()`>> | Constructs an XML element from arguments

| <<hql-xmlforest-function,`xmlforest()`>> | Constructs an XML forest from the arguments
| <<hql-xmlconcat-function,`xmlconcat()`>> | Concatenates multiple XML fragments to each other
| <<hql-xmlpi-function,`xmlpi()`>> | Constructs an XML processing instruction

| <<hql-xmlexists-function,`xmlexists()`>> | Checks if an XQuery or XPath expression exists in an XML document
| <<hql-xmlagg-function,`xmlagg()`>> | Aggregates XML elements by concatenation
| <<hql-xmltable-function,`xmltable()`>> | Turns an XML document into rows
|===

[[hql-xmltable-function]]
=== `xmltable()`

A <<hql-from-set-returning-functions,set-returning function>>, which turns an XML document argument into rows.
Returns no rows if the document is `null` or the XPath expression resolves to no nodes.

[[hql-xmltable-bnf]]
[source, antlrv4, indent=0]
----
include::{ql-function-extras-dir}/xmltable_bnf.txt[]
----

The first argument is the XPath expression. The second argument represents the XML document expression.

Columns that ought to be accessible via the `from` node alias are defined in the `columns` clause,
which can be of varying forms:

* Value attributes - denoted by a `castTarget` after the name, will cast the content of the XML node matching the XPath expression of the column
* Query attributes - denoted by the `xml` type after the name, returns the XML node matching the XPath expression of the column
* Ordinal attributes - denoted by the `for ordinality` syntax after the name, gives access to the 1-based index of the currently processed XML node

----
====

The `lateral` keyword is mandatory if one of the arguments refer to a from node item of the same query level.

[[ql-xml-dialect-support]]
=== Dialect support

The following tables describe registered Hibernate implementations, including native SQL and emulation.
A registered function may still have restrictions on clauses, argument types, paths, or null/error behavior; see its description in this appendix.
These tables are an implementation inventory, not the result of executing every function on every database.

The inventory contains 9 functions: `xmlagg()`, `xmlcomment()`, `xmlconcat()`, `xmlelement()`, `xmlexists()`, `xmlforest()`, `xmlpi()`, `xmlquery()`, `xmltable()`.
`All` and `All other functions` refer to this inventory.
Version profiles without an explicit threshold use the dialect constructor's default; they do not necessarily identify the latest server version.
Azure SQL uses a cloud capability profile rather than a numbered SQL Server release.

==== Core dialects

[cols="3,4,4",options="header"]
|===
|Dialect / version profile |Available functions |Unavailable functions
|`AzureSQLServerDialect` (cloud profile), `DB2Dialect` (11.1), `DB2iDialect` (7.2), `DB2zDialect` (12.1), `OracleDialect` (19.0), `PostgreSQLDialect` (14.0), `PostgresPlusDialect` (14.0), `SQLServerDialect` (12.0), `PostgreSQLDialect` (16.0), `PostgreSQLDialect` (17.0), `PostgreSQLDialect` (18.0), `SQLServerDialect` (13.0), `SQLServerDialect` (14.0), `SQLServerDialect` (16.0), `SQLServerDialect` (17.0), `OracleDialect` (21.0), `OracleDialect` (23.0) |All |None
|`CockroachDialect` (23.2), `HSQLDialect` (2.6.1), `MariaDBDialect` (10.6), `MySQLDialect` (8.0), `SpannerDialect` (unversioned default), `SpannerPostgreSQLDialect` (14.0), `SybaseDialect` (16.0), `MySQLDialect` (8.0.11), `MySQLDialect` (8.4), `MariaDBDialect` (11.7) |None |All
|`H2Dialect` (2.1.214), `H2Dialect` (2.2.220) |All except the functions in the next column |`xmlagg()`, `xmlexists()`, `xmlquery()`, `xmltable()`
|`HANADialect` (2.0.50), `SybaseASEDialect` (16.0) |`xmltable()` |All other functions
|===

H2 registers XML construction functions but not `xmlquery()`, `xmlexists()`, `xmlagg()`, or `xmltable()`.
HANA and Sybase ASE register only `xmltable()` from this family.
SQL Server implements much of this family using database-specific rendering or emulation.
