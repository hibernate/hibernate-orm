== Preface

Hibernate is an object/relational mapping (ORM) framework for Java applications.

Hibernate maps Java domain models to relational data and supports business logic implemented in Java, in the database, or across both.
Applications can combine entity-based persistence with native SQL and stored procedure calls, using Hibernate’s result mapping facilities to translate query results into Java objects.
