==== Custom collection types

[[collection-type-ann]]The `@CollectionType` annotation provides the ability to use a custom
link:{javadoc-base}/org/hibernate/usertype/UserCollectionType.html[`UserCollectionType`]
implementation to influence how the collection for a plural attribute behaves.

Consider a "unique list" that combines the ordering of a `List` with the uniqueness of a `Set`.

`UniqueListWrapper` is the `PersistentCollection` implementation for the "unique list" semantics.  See <<collection-wrapper>> for more details.

For cases where an application wants to apply the same custom type to all
plural attributes of a given classification, Hibernate also provides
`@CollectionTypeRegistration`.
This annotation may also be placed on a `package-info.java` or `module-info.java`.
