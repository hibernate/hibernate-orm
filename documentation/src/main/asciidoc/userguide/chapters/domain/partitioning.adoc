[[partitioning]]
=== Partition keys
:example-dir-partition-key: {core-project-dir}/src/test/java/org/hibernate/orm/test/mapping/identifier
:domain-partitioning-extrasdir: extras

A database table may be divided into physical partitions according to partition keys and a partitioning scheme.

Due to the nature of partitioning, it is vital for the database to know the partition key of a row for certain operations,
like SQL update and delete statements. If a database doesn't know the partition of a row that should be updated or deleted,
then it must look for the row in all partitions, leading to poor performance.

The `@PartitionKey` annotation identifies a partition key column so Hibernate can include it
in the predicates of SQL update and delete statements.
