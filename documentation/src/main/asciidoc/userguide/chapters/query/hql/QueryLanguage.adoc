[[query-language-function-contributors]]
=== Contributing functions

A link:{doc-javadoc-url}org/hibernate/boot/model/FunctionContributor.html[`FunctionContributor`]
registers custom HQL functions, including scalar, aggregate, and set-returning functions.
Its `contributeFunctions()` callback receives `FunctionContributions`, which provides access to
the link:{doc-javadoc-url}org/hibernate/query/sqm/function/SqmFunctionRegistry.html[`SqmFunctionRegistry`].
Choose a descriptor appropriate to the function's arguments, result type, and SQL rendering:

* `namedDescriptorBuilder()` creates a builder for a scalar function rendered as a database function call.
* `namedAggregateDescriptorBuilder()` creates a builder for an aggregate function.
* `namedSetReturningDescriptorBuilder()` creates a builder for a function that returns rows for use in the `from` clause.

Configure the builder, then call `.register()` to add the descriptor to the registry.
Obtaining or configuring a builder alone does not register the function.

The registry also supports SQL-pattern descriptors and custom function descriptors.
Registration describes how Hibernate validates and translates a function call; it does not
create the function in the database.

Expose a contributor through Java service loading by listing its implementation class in
`META-INF/services/org.hibernate.boot.model.FunctionContributor`.
For programmatic registration during native bootstrap, use
link:{doc-javadoc-url}org/hibernate/cfg/Configuration.html#registerFunctionContributor(org.hibernate.boot.model.FunctionContributor)[`Configuration.registerFunctionContributor()`]
or link:{doc-javadoc-url}org/hibernate/boot/MetadataBuilder.html#applyFunctions(org.hibernate.boot.model.FunctionContributor)[`MetadataBuilder.applyFunctions()`].
Complete registration during `contributeFunctions()` and retain neither its supplied
`FunctionContributions` nor the mutable registry after the callback returns.
See link:{doc-dialect-provider-url}#dialect-provider-function-contracts[function contribution contracts]
for lifecycle and descriptor details.
