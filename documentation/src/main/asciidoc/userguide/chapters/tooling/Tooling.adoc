[[tooling]]
== Build Tool Integration

Hibernate provides build-time enhancement, annotation processing, and reverse engineering
for Gradle, Maven, and Ant. Choose the service according to its input and required output.

[[tooling-services]]
=== Choosing build-time services

[cols="2,3,3",options="header"]
|===
|Service |Input and output |Integration
|<<BytecodeEnhancement,Bytecode enhancement>>
|Compiled model classes become enhanced classes.
|The ORM Gradle plugin, Maven `enhance` goal, or Ant enhancement task.
|<<tooling-modelgen,Annotation processing>>
|Model and repository sources produce metamodel classes and other generated code.
|Compiler annotation-processor configuration, independently of the enhancement plugin.
|<<tooling-reveng,Reverse engineering>>
|An existing database schema produces entity sources or other exported artifacts.
|Gradle reverse-engineering tasks, Maven goals, or Ant exporters.
|<<tooling-schema,Schema management>>
|Mappings produce schema commands, scripts, or validation results.
|Schema Tooling APIs and supported Maven/Ant entry points.
|<<tooling-maven-transformhbm,Mapping transformation>>
|Legacy `hbm.xml` files produce ORM XML mappings.
|Maven `transformHbm`.
|===
